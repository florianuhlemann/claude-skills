# pcb-audit skill — changelog

## 0.2.0 — 2026-10-19
Method from seven independent audits of two boards (three and four rounds, all without kicad-cli): an audit without KiCad is first-class, sign-offs are re-measured on the current revision, lengths are routed copper, and the fab files themselves are checked.
- `SKILL.md`: two tiers stated once (Tier A from the files, always; Tier B adds kicad-cli ERC/DRC/parity re-runs), `preflight.sh` prints the tier, "checks run" names what was taken as given; stance adds "a sign-off is a claim about this revision", "datasheet condition, not just the number", "audit what gets built"; sign-off sweep as a step of every audit; report opens with the six standing questions, gains "signed off as OK but not true on this revision", "checked and found correct", "decisions reviewed and endorsed" and a "when" column (`before ordering` / `this spin if cheap` / `next revision` / `docs`); `gated` names measurement, probe point or method and accept limit; IDs unique per report, cited elsewhere with the report file name; per-gate lines for environment vs. electrical margin, datasheet condition, reset state, connector misplug, scenario walk-through, hole tolerance stack, routed copper, fab-file alignment, DFM list, justification diversity, cross-document numbers. Description names the no-KiCad mode and the new checks. 132 lines.
- `references/audit-procedure.md`: tier table per check; inputs gain the netlist export and review documents; sign-off sweep (where to look, classes of stale sign-offs, justification-diversity commands, cross-document numbers); gate 1 environment margin; gate 3 datasheet condition with the cases seen; gate 4 reset state, misplug, scenario walk-through, no-substitute parts; gate 5 hole tolerance stack table and the shared-drill-table finding class; gate 6 routed copper with `net_path.py --pairs`, planes from `board_stats.py`; gate 7 fab-file alignment, DFM table, generators; "when" and status guide. Self-audit checklist header corrected: pcb-design 0.7.0 no longer carries it, this is the only copy.
- `references/findings-template.md`: rewritten around the standing questions, the findings table with "when", the three new sections, tier and "taken as given" in checks run; keep-it-short rule with the reason.
- `references/lessons-learned.md`: section "From the audits" with the drill-origin offset that DRC passed and the loop length cited three revisions after it was measured; earlier entries unchanged.
- New `scripts/pcb_board.py`: shared board reader (custom-pad primitives, arcs with true length, zones and fills, Edge.Cuts, stackup) and copper walkers; `check_decoupling.py`'s geometry and D5 walker moved here verbatim, plus a Dijkstra router (`NetGraph`, `route`).
- New `scripts/pcb_nets.py`: pad nets from the board; `--netlist` parity with the export (Tier A substitute for DRC parity), `--write-net` netlist from the board that `audit_netlist.py` and `check_decoupling.py` read unchanged.
- New `scripts/check_fab_files.py`: RS-274X and Excellon reader (folder or zip); centred flash or region at every plated drill on both outer layers with the common offset named, holes inside the outline, outline vs. documented size and the board, drill table and positions vs. the board.
- New `scripts/net_path.py`: routed copper length and vias between two pads, straight line beside it, "zone only" / "through the plane" diagnosis, `--pairs` against claimed lengths.
- New `scripts/board_stats.py`: outline, layers, stackup, finish, tracks per class, vias, zones and fill pieces, drill table, parts per side, DFM evidence, with flags.
- `scripts/check_decoupling.py`: uses `pcb_board.py` (identical findings on the self-test fixtures, checked against 0.1.0), adds a routed-length column; custom pads now cover their primitives, not only the anchor. `audit_netlist.py`: usage header names the Tier A input (logic unchanged). `preflight.sh`: kicad-cli optional, tier printed, new self-tests run; `unzip` dropped (zip read in Python). `scripts/README.md` rewritten by gate and tier.

## 0.1.0 — 2026-10-19
First release: the checking counterpart of pcb-design, used stand-alone on any KiCad 10 project and at every ⏸ gate of pcb-design's workflow.
- `SKILL.md`: auditor's stance (independent, evidence per finding, premises checked against the board, report rather than fix), how an audit is run (stand-alone or one gate, inputs, full vs. reduced coverage), per-gate checks 1–8, the `Decouples` convention, findings format (`A<gate>-<nn>`, blocker/major/minor/note, PASS / PASS with findings / FAIL, `docs/audits/gate<N>-<YYYY-MM-DD>.md`).
- `references/audit-procedure.md`: inputs and coverage table, per-gate detail, independent audit before the first order tag, the self-audit checklist (copied from pcb-design), severity guide. `references/findings-template.md`: report skeleton with designer response table. `references/lessons-learned.md`: the audit-relevant incidents, copied verbatim from pcb-design.
- New `scripts/check_decoupling.py`: D1 unassigned cap, D2 assigned to a pin on another net, D3 supply pin without a cap (netlist); D4 pad-to-pin distance, D5 cap reached only through a via or the plane, D6 nearest same-net cap is not the assigned one, D7 no return via at the cap (board). Reads both netlist field forms, `--json`, `--self-test` (planted failures fail, clean variant passes), `--write-fixtures`.
- Moved from pcb-design: `audit_netlist.py` (header now names the audit context and the `.kicad_net` export), `check_entry_angles.py`, `check_track_geometry.py`. Sourced here, copied by pcb-design: `drc_gate.py`, `lint_stale_values.py`. Copies of pcb-design's `sexpr.py` and `kicad_env.sh`. New `scripts/preflight.sh` (python3, kicad-cli, every self-test) and `scripts/README.md`.
